Good practice

Decide the sample size before the test and do not stop early because the result looks good: checking repeatedly inflates false positives. Run for whole weeks so that weekdays and weekends are both covered. With more than two variants, the confidence level is adjusted (Bonferroni) so the overall error rate stays the one you chose.
